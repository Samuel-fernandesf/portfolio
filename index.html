Sobre Mim

Sou Técnico em Informática pelo Instituto Federal de São Paulo (IFSP) – Campus Araraquara, onde também participo de um projeto de Iniciação Científica voltado ao desenvolvimento de software e à inovação na educação.

Para mim, estudar tecnologia vai muito além de aprender uma linguagem de programação ou utilizar uma ferramenta. Gosto de compreender o funcionamento das tecnologias que utilizo, desde a inicialização de um sistema operacional até a comunicação entre dispositivos em uma rede. Entender esses fundamentos me ajuda a enxergar a tecnologia como um sistema formado por diferentes partes que se complementam, e não como ferramentas isoladas.

Foi essa forma de aprender que despertou meu interesse por áreas como Desenvolvimento Full-Stack, Redes de Computadores, Homelab, Sistemas Operacionais Linux e Eletroeletrônica. Apesar de parecerem áreas distintas, todas compartilham os mesmos fundamentos da computação e se complementam na construção de sistemas completos.

Iniciação Científica · 2024 – Atual

Sistema educacional gamificado desenvolvido no contexto de uma pesquisa em Informática na Educação, baseado no conceito de Game-Based Student Response System (GSRS). O projeto busca oferecer uma alternativa livre e de código aberto a plataformas comerciais como o Kahoot!, explorando recursos voltados ao engajamento e ao feedback pedagógico.

Atuei no ciclo de desenvolvimento, desde o levantamento de requisitos e modelagem do banco de dados até a implementação da aplicação. O sistema evoluiu de uma aplicação monolítica em Flask para uma arquitetura desacoplada, utilizando Flask como API REST e React no frontend, com autenticação via JWT, criação de quizzes e organização por pastas, banco de questões, correção detalhada e interface responsiva.
